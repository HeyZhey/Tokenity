# ImageGen Prompt Set

All ten images used the built-in ImageGen tool in `ui-mockup` mode.

## Shared product brief

Design **Tokenity**, a Mac-native control plane for distributed local AI
inference across multiple Apple-silicon Macs. Produce one high-fidelity native
macOS/SwiftUI application window in a 16:10 landscape image, shown straight-on
with a slim title bar and left navigation sidebar.

Use the existing information architecture:

> Tokenity · Distributed AI · Overview · Cluster · Chat · Models ·
> Network / RDMA · API Access · Logs · Settings

The result must be minimal, classic, implementable in SwiftUI, and readable as
one coherent interface rather than a collage. Animal references must be abstract
and sophisticated. Avoid cute or photoreal mascots, cartoon styling, neon
cyberpunk, excessive glow or gradients, glassmorphism, glossy 3D icons,
oversized cards, phone UI, browser chrome, and watermarks.

## 01 — Snow Leopard Graphite

Create an Overview screen using graphite, warm ivory, snow white, muted steel
blue, and tiny green success accents. Use thin hairline separators, compact
information density, matte paper-like panels, and a faint brushed-metal sidebar.
An abstract snow-leopard mark is built from connected spots/nodes, with the
dotted logic repeated subtly in the cluster topology. Show Cluster State,
Resident Models, Selected Macs, Running, Auto routing healthy, Studio Alpha,
Studio Beta, `http://localhost:9100/v1`, memory bars, and Open Chat.

## 02 — Arctic Fox Ivory

Create a Cluster screen inspired by precision instruments and classic Apple
industrial design. Use arctic white, soft stone, charcoal, oxidized teal, and
small green status accents. A single abstract arctic-fox tail curve forms the
brand mark and traces the data path between Studio Alpha and Studio Beta.
Show Thunderbolt RDMA, Cluster Setup, Online, 128 GB, Tokenity Distributed,
Create Cluster, and Refresh Status.

## 03 — Octopus Ink

Create a dark Models screen in ink black, charcoal, parchment, muted copper, and
sparingly used cool cyan. An eight-arm radial topology mark suggests an octopus
only through curved network lines around a central token. Show Qwen3.5 122B and
Mistral Small with Loaded and Ready states, Format, Quantization, Memory, Nodes,
Load Model, Configure, Unload, and `2 Macs · RDMA`.

brand mark. Show Coordinator, Worker 1, Worker 2, Running, 3 Macs, 192 GB
Unified Memory, RDMA Ready, Model Pool, Qwen3.5 122B, Mistral Small, and Open

## 05 — Raven Ledger

## 06 — Tortoise Jade
